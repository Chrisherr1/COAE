## Garak 

It scans LLMs for common vulnerabilities, prompt injection, and jailbreaks.

It does this by giving the LLM prompts known to result in successful prompt injection or jailbreaking.

Depending on the responses, it determines if the attack vector was succesful.

---
## Install for Garak

```
pip install garak
```

---
## Use

Needs Model type, a Model name , and the attacks we want to scan (called probes).

* --model_type  - Allow us to Specify model (OpenAI, HuggingFace, etc)
* -- model_name - Allows us to Specify name
	* Must be in model_type to use name.
* --probes - allows us to give the probes(attacks) to run

First : garak --list_probes
	Gives us the list of attacks available.
	

---
## Garak detection 

Detectors = tell us if a attack has succeeded.
	1. mitigation.MitigationBypass
	2. dan.Dan

> We can see each failure rate for each detector, they will run multiple times for each detector.

Garak will produce 2 reports:
1. A JSON report with all prompts and responses used. (Contains used prompts)
2. A HTMl overview report. (Contains failure rates)
